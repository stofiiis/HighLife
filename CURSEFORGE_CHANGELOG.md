# HighLife - Latest Update

## Highlights

- Completely refreshed every HighLife item texture.
- Rebuilt the Drying Rack and Seed Mixer as detailed custom 3D blocks.
- Updated all crop growth stages with clearer visual progression.
- Redesigned the Seed Mixer, Infusion Wand, and Alchemy Flask interfaces.
- Added concise usage instructions to every HighLife item tooltip.

## Seed Mixer

- Fixed input handling for parent seeds, dirt, and optional bone meal.
- Parent seed slots now split matching stacked seeds correctly.
- Added clear slot tooltips and missing-ingredient status messages.
- Mixing results are delivered immediately while the interface remains open.
- Parent inputs are once again limited strictly to Mystic Herb Seeds.

## Progression

- Repaired advancement branches that previously referenced invalid parents.
- Added the **Master Workshop** challenge for collecting the complete processing setup.
- Added the **Gene Archive** challenge for completing ten successful seed crosses.
- Cleaned up advancement names and descriptions so internal registry IDs are no longer displayed.

## Effects And Audio

- Added new custom icons for Serenity, Thirst, Haze, and Peace.
- Improved effect naming and presentation.
- Replaced missing audio resources with reliable built-in Minecraft sound events.
- Preserved the custom first-person and third-person tool animations.

## Interface And Accessibility

- Added English and Czech instructions for every item.
- Improved Czech localization and removed untranslated technical names.
- Added clearer Seed Mixer progress and ingredient feedback.
- Standardized the visual style across all three custom interfaces.

## Compatibility

- Minecraft **1.21.11**
- NeoForge **21.11.38-beta**
- Java **21**

This build is designed specifically for Minecraft 1.21.11. Compatibility with other 1.21.x versions is not guaranteed.
